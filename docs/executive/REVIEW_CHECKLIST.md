# Review Checklist

- Apakah scope PR sesuai dengan ticket?
- Apakah ada tests yang relevan dan lulus?
- Apakah perubahan memiliki dokumentasi (spec / README / comment)?
- Apakah ada dampak terhadap database atau API? Jika ya, apakah ada migrasi dan dokumentasi?
- Apakah ada potensi regression pada fitur lain?
- Apakah code mengikuti Engineering Principles?
- Apakah ukuran PR kecil dan mudah direview?
- Apakah ada langkah rollout / rollback jika diperlukan?
