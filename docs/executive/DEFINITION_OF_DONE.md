# Definition of Done

Checklist untuk menandai task/PR sebagai selesai:

- Dokumen spesifikasi dan acceptance criteria terupdate.
- Unit/integration tests ditambahkan dan lulus.
- Perubahan telah direview dan disetujui (PR review).
- Database migration (jika ada) terdokumentasi dan diuji di staging.
- API changes didokumentasikan dan memiliki contract tests.
- UI/UX sesuai desain dan teruji secara manual bila perlu.
- Semua linters dan pemeriksaan CI lulus.
- CHANGELOG atau PROJECT_LOG terupdate bila relevan.
