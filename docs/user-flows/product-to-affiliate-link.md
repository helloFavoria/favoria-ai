# Product to Affiliate Link Flow

## Goal

Move from product creation to affiliate link generation in a predictable path.

## Flow

1. Authenticated user opens Products.
2. User creates or selects a product.
3. User opens the product detail or actions panel.
4. User chooses Generate Affiliate Link.
5. System creates the link and displays the generated URL.
6. User can copy or share the link.

## Success Criteria

- Link is generated once the product exists.
- User can copy and reuse the generated link immediately.

## Edge Cases

- Missing product title or price
- Duplicate link generation request
- Permission denied
