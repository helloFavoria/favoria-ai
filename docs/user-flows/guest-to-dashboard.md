# Guest to Dashboard Flow

## Goal

Allow a new visitor to create an account and reach the dashboard safely.

## Flow

1. Guest opens the landing page.
2. Guest clicks Register.
3. Guest enters email, password, and display name.
4. System validates the input.
5. Account is created and the user is redirected to the dashboard.
6. If the registration fails, the user stays on the form and sees a clear error.

## Success Criteria

- User reaches the dashboard without additional manual steps.
- The system shows visible feedback for success or failure.

## Edge Cases

- Duplicate email
- Weak password
- Network error
